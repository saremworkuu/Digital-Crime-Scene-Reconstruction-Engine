# Scenario 1 Sample Data

This directory contains sample log files for testing the Digital Crime Scene Reconstruction Engine.

## Files

- `auth.log` - Authentication logs
- `access.log` - Web server access logs
- `windows-security.evtx` - Windows security event logs
- `capture.pcap` - Network packet capture

## Scenario Description

This scenario demonstrates a typical security incident involving unauthorized access attempts and lateral movement.
