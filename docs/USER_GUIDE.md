# User Guide

## Getting Started

### Installation
1. Clone the repository
2. Run `docker-compose up` to start all services
3. Navigate to `http://localhost:3000`

### First Login
1. Default admin credentials: admin/admin123
2. Change password on first login
3. Create additional users as needed

## Case Management

### Creating a Case
1. Click "New Case" from the dashboard
2. Enter case name and description
3. Click "Create"

### Adding Evidence
1. Open a case
2. Go to the Evidence tab
3. Drag and drop files or click to upload
4. Wait for parsing to complete

## Analysis

### Timeline View
- Events are displayed chronologically
- Use the zoom controls to adjust time range
- Click on events to view details
- Use filters to narrow down events

### Attack Graph
- Visual representation of entities and relationships
- Click nodes to view entity details
- Drag to rearrange the graph
- Use the legend to understand node types

### Detections
- View detected security incidents
- Filter by severity
- Click to view detection details
- Mark detections as reviewed

## Reports

### Generating a Report
1. Go to the Reports tab
2. Click "Generate Report"
3. Select sections to include
4. Choose format (PDF/Word)
5. Click "Download"
