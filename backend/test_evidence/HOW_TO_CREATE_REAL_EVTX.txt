Creating a genuine .evtx sample on Windows
==========================================

An EVTX file is a binary Windows Event Log export. The XML file in this bundle
is a readable example, NOT a genuine .evtx file.

To export a genuine sample from the Windows System log, open PowerShell and run:

    wevtutil epl System "$env:USERPROFILE\Desktop\sample_system.evtx" /ow:true

This exports events from your own computer and may include host-specific details.
Review the file before sharing it. For a cleaner test, use a disposable Windows VM.

Important for DCSRE:
- A .evtx file will only produce events if get_parser() maps .evtx to a parser
  that actually understands Windows EVTX binary format.
- Renaming XML or a text file to .evtx does not convert it.
- The included .pcap and .pcapng files contain a few synthetic Ethernet/IPv4/UDP
  packets. Their contents are for parser testing, not real network evidence.
- The .auth, .csv and .log files are synthetic and contain documentation-only IPs.
